# Hafezieh

## Interactive 3D Reconstruction, Virtual Environment & VR

Hafezieh is a detailed 3D reconstruction and interactive virtual environment project based on the Hafezieh complex in Shiraz, Iran.

The project began as a detailed 3D modeling effort and was subsequently transformed into an interactive real-time environment using the Unity game engine.

A virtual reality version was also developed for Meta Quest, allowing the reconstructed environment to be experienced immersively.

The project was additionally deployed for web-based virtual exploration.

# 3D Reconstruction

The Hafezieh environment was meticulously modeled in Autodesk Maya.

The modeling process involved reconstructing the architectural environment and its major structural and decorative components as a coherent digital scene.

The objective was not simply to create a static architectural model, but to create a sufficiently complete environment that could subsequently be explored interactively.

---

# Interactive Environment

After the 3D reconstruction stage, the environment was implemented using the Unity game engine.

The Unity implementation transformed the reconstructed geometry into a real-time interactive environment.

The environment supported virtual exploration and navigation through the reconstructed site.

The implementation included interactive scene navigation and different viewing modes for exploring the environment.

---

# Virtual Reality

A dedicated VR version of the Hafezieh environment was developed for Meta Quest.

This extended the project from desktop / web-based visualization toward an immersive environment.

The conceptual progression was:

3D Model
→
Interactive Environment
→
Real-Time Exploration
→
VR Environment
→
Meta Quest

This part of the project is particularly relevant to immersive visualization, spatial interaction, and embodied digital environments.

---

# Web Deployment

The Hafezieh environment was also prepared for web-based virtual exploration.

This allowed the reconstructed environment to be presented as an interactive digital space rather than only as a rendered image or offline 3D scene.
