# Dome of the Rock

## Detailed 3D Reconstruction and Architectural Modeling

This project involved the detailed 3D modeling and digital reconstruction of the Dome of the Rock based on the real architectural structure in Jerusalem.

The project focused on detailed architectural reconstruction, geometric modeling, scene construction, and visual presentation.

Unlike the Hafezieh project, this project is presented primarily as a 3D reconstruction and modeling project rather than as a virtual reality deployment.

---

# Project Overview

The reconstruction involved the creation of detailed digital geometry representing architectural structures and decorative elements of the site.

The project required translating the physical architectural structure into a detailed digital 3D representation.

The general workflow was:

Architectural Reference
→
Geometric Interpretation
→
3D Reconstruction
→
Detailed Architectural Modeling
→
Scene Construction
→
Materials / Textures
→
Visualization

---

# Modeling

The project involved detailed modeling of architectural structures and components, including:

- columns
- arches
- domes
- structural elements
- decorative architectural elements
- interior and exterior geometry
- environmental components

The goal was to create a detailed digital representation of the architectural environment rather than a simplified conceptual model.

# Representation Perspective

The project can be viewed as an early example of constructing an explicit computational representation of a complex physical environment.

The process can be summarized as:

Physical Environment
→
Visual Reference
→
Geometric Interpretation
→
Explicit 3D Representation
→
Detailed Digital Environment

This experience later became relevant to my interest in computational representations of physical environments and visual information.

---

# Relation to Current Research

My current work increasingly focuses on learned representations rather than manually constructed geometric representations.

This creates a conceptual progression:

Explicit 3D Modeling
→
Digital Reconstruction
→
Computer Vision
→
Learned Visual Representations
→
Embodied Intelligence

The Dome of the Rock reconstruction represents an earlier stage of this trajectory, where the representation was explicitly constructed through 3D modeling.

My current research investigates how useful representations can instead be learned from data.
